# Personal Portfolio (React + Vite)

## Run locally (Windows PowerShell)
    npm install
    npm run dev

## Build
    npm run build

Edit your content in `src/data/siteData.js`, `src/data/skills.js` and `src/data/projects.js`.
Put your CV at `public/cv.pdf` and your photo at `public/images/profile.svg` (or change the path in siteData.js).
